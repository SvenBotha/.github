# .github

Default community health files for every `SvenBotha` repository, public and private.

- `.github/PULL_REQUEST_TEMPLATE.md` pre-fills the description of new pull requests in any repo that has no template of its own.
- To override for one repo, add `.github/PULL_REQUEST_TEMPLATE.md` to that repo.
- GitHub reads these files from this repo's default branch only, so changes take effect on merge.

Reference: [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
